# opskit

Personal OPS Kit — scripts and configs for server provisioning and maintenance.

## Scripts

| Script | Description |
|---|---|
| [bootstrap.sh](scripts/bootstrap.sh) | Initial setup for Debian/Ubuntu servers/VMs |

## Running Scripts

**Via curl:**

```bash
curl -fsSL https://raw.githubusercontent.com/eduardokairalla1/opskit/main/scripts/<name>.sh | sudo bash
```

**Via clone:**

```bash
git clone https://github.com/eduardokairalla1/opskit.git
sudo ./opskit/scripts/<name>.sh
```
